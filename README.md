# sumberfarm 
Aplikasi ini digunakan untuk *monitoring kandang ayam*, termasuk data produksi, penjualan, pengeluaran, dan umur ayam otomatis.

## Fitur
- Login/logout dengan email
- Dashboard monitoring ayam
- Input data produksi, penjualan, dan pengeluaran
- Hitung otomatis umur ayam (minggu & hari)
- Filter data berdasarkan bulan dan tahun
- Notifikasi boros pakan
- Responsive dan mudah digunakan

## Teknologi
- HTML, CSS, JavaScript
- Firebase (Authentication & Firestore)
- Hosting: GitHub Pages / Netlify / Firebase Hosting
